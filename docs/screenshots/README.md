# Screenshots

The README points at four images in this folder. Take them from a running
StreamTorrent and save them here under these exact names:

| File | What to capture |
| --- | --- |
| `torrent-list.png` | The main window with a few torrents in the list |
| `torrent-details.png` | A torrent opened up, showing the folder tree |
| `player.png` | A video playing, with the bars showing |
| `preferences.png` | The Preferences window |

PNG, and whatever size the window is — GitHub scales them down. Nothing
personal in shot: the file names in a torrent are visible in these.
